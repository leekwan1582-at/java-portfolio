# Portfolio - Java Programming for Developers

## INSTRUCTIONS FOR CANDIDATE
Requirements
In this portfolio project, you will create a software design that uses Java to solve a
particular problem. You should choose a problem that justifies the use of Java. The
software design must meet the following requirements

- The use case should make use of the strengths of Java
- The software design must consist of the following:
	- A write-up that describes the problem, why Java is suitable and why alternatives to Java will not be suitable
	- A class diagram that shows all the classes and their relationships with each other. The class diagram should show at least two attributes relevant to the business case.
	- An object diagram that shows one possible state of all the classes.
- The software design must be submitted as one PDF document.

## Marking Criteria
### Write-Up
The software design report must have a write-up that covers the following points:
- One justification for using Java – your justification should mention a strength of Java
- State one possible alternative instead of using Java, and why it is not suitable

### Class Diagram
#### Your class diagram must consist of the following:
- At least three classes
- You must have at least one class that can be instantiated.
- You must have at least one directed association
- You must demonstrate inheritance at least once
- You must override at least one method
- You must have at least one interface or abstract base class.

### Object Diagram
#### Your object diagram must consist of the following:
- For each class, show at the values for at least one object
